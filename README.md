# FF ULTIMA One-line

A fork of [FF ULTIMA](https://github.com/soulhotel/FF-ULTIMA) with a one-line layout
for the address bar, tabs and navigation buttons, retaining Ultima's themes and settings.

> Tested with Firefox 157 and Nova on Windows in dark mode.

*Screenshots — coming soon.*

**[Ultima Wiki](https://ff-ultima.github.io/docs/getting-started)** ·
**[One-line settings](docs/one-line.md)**

Follow Ultima's installation guide using the files from **this repository**
instead of the upstream download.
